# v1 — ship today

v1 is the factory you can run without E2B keys or a GitHub App.

## In scope

- Allowlist + denylist as code.
- Deterministic policy gate + policy lab.
- Scout heuristics + one-in-flight tick.
- Task packets with objective / non-goals / acceptance / abort.
- Human freeze in the operator console.
- Draft PR **body** generation (no unattended `gh pr create` to strangers).
- GitHub Action that no-ops unless the repo is `oss-foundry` itself (self-tick).
- Reuse of orca-fleet `oss-contribute` as the worker protocol.

## Out of scope (v2)

- Real E2B/Daytona sessions.
- Grok scout overlay.
- Live scorecard halt from GitHub API.
- GitHub App installation.

## Operator loop

1. Open Foundry.
2. Confirm Wave 0 packet `orca-fleet#42` is the first freeze.
3. Approve with a one-line attest.
4. Advance: implement (host worktree via Orca) → review → draft body.
5. Copy the body into a real draft PR from your fork, or hand the packet to `oss-contribute`.
6. Do not run a second tick until that packet is terminal.

## GitHub Action

`.github/workflows/oss-tick.yml` runs every 6 hours and on dispatch.

It does **not** open PRs. It:

- Checks that `allowlist.yaml` still parses.
- Fails if a denylisted repo id appears in the allowlist.
- Opens (or updates) a `packet` issue on `oss-foundry` titled `tick: next` **only** when `FOUNDRY_LIVE=true` is set on the repo. Default is dry.

## Hand-off to Orca

```
# In a clone of the target, with Orca + oss-contribute linked:
"contribute to this project: <issue url from the packet>"
```

Foundry is the gate. Orca is the hands.
