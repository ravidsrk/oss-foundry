# v1 — ship today

v1 is the factory you can run without E2B keys or a GitHub App.

## In scope

- Allowlist + denylist as `allowlist.yaml` (sole source).
- Deterministic policy gate. Unknown policy without fetched docs is deny.
- Scout heuristics + one-in-flight tick, including `submitted`.
- Task packets with objective / non-goals / acceptance / abort.
- Human freeze in the operator CLI.
- Draft PR **body** generation (no unattended `gh pr create` to strangers).
- GitHub Action that parses the YAML and no-ops unless `FOUNDRY_LIVE=true` (self-tick issue only).
- Reuse of orca-fleet `oss-contribute` as the worker protocol.
- Scorecard halt consulted on tick / queue / approve (`allowlist.yaml` caps).
- Tick skips named issues that already have an open closing-keyword PR.
- Scope overflow (`maxFiles` / `maxDiffLines`) parks the packet.
- No invented issue numbers when the named list is empty.
- No placeholder SHA evidence.

## Out of scope (v2)

- Real E2B/Daytona sessions.
- Grok scout overlay (not shipped).
- GitHub App `POST` to stranger repos (403 unless installed).

## Operator loop

1. `node --experimental-strip-types factory/cli.ts status`
2. ColeMurray#1652 is `followed-up` (draft, slot released). Do not merge it. Do not tick while any other packet is `submitted`.
3. When idle: `tick` → `approve --note` → hand to `oss-contribute` → attach evidence → `body` → open a **draft**.
4. Do not run a second tick until that packet is `followed-up`, `merged`, `parked`, or `rejected`.

## GitHub Action

`.github/workflows/oss-tick.yml` runs every 6 hours and on dispatch.

It does **not** open contribution PRs. It:

- Parses `allowlist.yaml` (not substring search).
- Fails if a denylisted repo id appears under `repos:` (including `stablyai/orca`).
- Opens (or updates) a `packet` issue on `oss-foundry` titled `tick: next packet (human freeze required)` **only** when `FOUNDRY_LIVE=true` is set on the repo. Default is dry.

## Hand-off to Orca

```
# In a clone of the target, with Orca + oss-contribute linked:
"contribute to this project: <issue url from the packet>"
```

Foundry is the gate. Orca is the hands.
